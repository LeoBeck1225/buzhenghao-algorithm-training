## 边界情况

- 
- capacity = 1，put(1,1)、put(2,2) 后 get(1) → -1，get(2) → 2
- get 不存在的 key → -1
- put 已存在的 key 更新值 → get 返回新值，容量不变
- 更新已有 key 后它成为最近使用，淘汰时不会先被淘汰
- get 某 key 后该 key 成为最近使用，淘汰的是别的 key
- put 时容量刚好满 → 插入新键后再淘汰尾部
- 容量满且 put 已存在的 key → 不淘汰任何键
