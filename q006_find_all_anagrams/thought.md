## 我的第一想法（未使用 AI）
1.这题和第一题有点相似，都用到了异位词。但是这个长度是固定的。那就固定窗口长度l去扫描，判断窗口内的字符计数是否等于异位词p的计数
2. 采用一个变量d去记录“有多少个字符不同”，不用match是我觉得逐一比较代码量太大了

## 复杂度

- 时间：O( n)
- 空间：O(1)

## 边界情况

- 
- s = "", p = "a" → []
- s = "a", p = "ab" → []
- s = "a", p = "a" → [0]
- s = "ab", p = "a" → [0, 1]
- s = "ab", p = "ba" → [0]
- s = "abd", p = "b" → [1]
- s = "cbaebabacd", p = "abc" → [0, 6]
- s = "abab", p = "ab" → [0, 1, 2]
- s = "aaaa", p = "aa" → [0, 1, 2]
