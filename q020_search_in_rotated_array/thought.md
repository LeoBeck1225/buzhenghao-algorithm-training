## 经 AI 提示后的补充（这部分不是原话，单独记录）

### ① 不需要多次二分

| 方案 | 思路 | 代码量 |
|---|---|---|
| **一次二分**（采用） | 每轮判断哪半有序，再看 target 是否落在有序半区 | ~15 行 |
| 两次二分 | 先找旋转点（最小值），再在对应区间二分 | ~25 行 |

两次二分也能 AC，但多一次遍历就多两处边界，容易写错。

### ② 核心逻辑

```python
if nums[left] <= nums[mid]:          # 左半 [left..mid] 有序
    if nums[left] <= target < nums[mid]: right = mid - 1
    else:                                left = mid + 1
else:                                # 右半 [mid..right] 有序
    if nums[mid] < target <= nums[right]: left = mid + 1
    else:                                 right = mid - 1
```

旋转后数组至多两段升序，所以 `mid` 处**必有一半是完全递增的**，
判断 target 是否落在这个有序半区的区间内即可排除一半。

### ③ 两处措辞修正

- 题目保证元素**互不相同** → 是严格递增，不是"不严格递增"
- 不需要**显式找到断点**：每轮判断哪半有序，断点会被自然排除

### ④ 两个边界细节

- `nums[left] <= nums[mid]` 用 `<=`：当 `left == mid`（区间只剩两个元素）时左半仍视为有序
- 判断 target 是否在有序区间用**左闭右开**：`nums[left] <= target < nums[mid]`
  （`nums[mid]` 已单独判过相等，所以右端取开）
