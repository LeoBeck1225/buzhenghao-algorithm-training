## AI

（把打家劫舍的 DP 机制从"定义 → 决策 → 转移 → 走表"重新讲一遍，见下）

### 一、把问题翻译成"每间房做一次选择"

站在第 `i` 间房门口，你只有两个选择：**偷** 或 **不偷**。答案就是这一串选择的总和最大。

### 二、dp[i] 的定义

> `dp[i]` = **只考虑前 i 间房**（即 `nums[0..i-1]`）时，能偷到的最大金额。

关键词是"**只考虑前 i 间，不要求偷第 i 间**"。很多人卡住，是因为把它误读成"第 i 间必偷"。

### 三、转移：对第 i 间，只有两种决策

| 决策 | 后果 | 收益 |
|---|---|---|
| **不偷 i** | 前 i-1 间随意 | `dp[i-1]` |
| **偷 i** | i-1 绝对不能偷，剩下的只能从前 i-2 间里选 | `dp[i-2] + nums[i-1]` |

取较大者：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
```

### 四、为什么"偷 i"用 dp[i-2]，而不是 dp[i-1]

因为 `dp[i-1]` 的最优方案**可能已经偷了 i-1**，再偷 i 就相邻冲突了。

而 `dp[i-2]` 回答的是"前 i-2 间的最优"，它已经包含了「i-2 偷」和「i-2 不偷」两种情况的更大者，所以**不会漏解**。

注意：`dp[i-2]` ≠ "必偷 i-2"。

### 五、完整走表：`[2, 7, 9, 3, 1]`

| i | 对应房间 | dp[i-1]（不偷） | dp[i-2]+x（偷） | dp[i] |
|---|---|---|---|---|
| 0 | — | — | — | **0** |
| 1 | 2 | dp[0]=0 | dp[-1]+2=2 | **2** |
| 2 | 7 | 2 | 0+7=7 | **7** |
| 3 | 9 | 7 | 2+9=11 | **11** |
| 4 | 3 | 11 | 7+3=10 | **11** |
| 5 | 1 | 11 | 11+1=12 | **12** |

答案 `dp[5] = 12`，对应偷 `2 + 9 + 1`。

### 六、滚动变量为什么等价

```
prev2 ← dp[i-2]
prev1 ← dp[i-1]
循环一行：prev2, prev1 = prev1, max(prev1, prev2 + x)
```

每次只保留"前两格"，因为 `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`。

### 七、为什么不能用贪心

直觉上会想"先偷最大的 9，再偷不相邻的"，但 `[2,7,9,3,1]` 里偷 `9 + 1 = 10`，而偷 `2 + 9 + 1 = 12` 更大。
**局部最优 ≠ 全局最优**，这正是 DP 存在的理由。

## AI

（DP 系统复习，见下）

### 一、DP 的本质，一句话

> 把「从前往后做一串选择」压缩成「**只需决定最后一步**，剩下的交给已经算好的子问题」。

### 二、做题五步法

| 步骤 | 要回答的问题 | 常见坑 |
|---|---|---|
| 1 状态定义 | `dp[?]` 表示哪个子问题的答案 | 定义含糊 → 转移写不出 |
| 2 转移方程 | 最后一步有几种可能？各对应哪个子问题？ | 漏掉某一种可能 |
| 3 初始化 | 最小规模（空/1 个）的答案是什么？ | `dp[0]=0` 还是 `inf` |
| 4 遍历顺序 | 依赖项是否已经算好？ | 区间 DP 要按长度 |
| 5 答案位置 | `dp[n]`？`max(dp)`？`dp[0][n-1]`？ | LIS 忘记取 max |

### 三、状态定义的四大家族

| 家族 | 定义 | 你做过/要做的题 | 答案 |
|---|---|---|---|
| **前 i 个** | 前 i 个元素的最优 | 198 打家劫舍 | `dp[n]` |
| **以 i 结尾** | 必须以 i 结尾时的最优 | 300 LIS、5 回文子串 | `max(dp)` |
| **区间** | 区间 `[i,j]` 的最优/是否 | 5 回文（`dp[i][j]`）、516 | `dp[0][n-1]` |
| **容量** | 凑出容量 i 的最优 | 322 零钱兑换 | `dp[amount]` |

### 四、"前 i 个" vs "以 i 结尾"差在哪

- **前 i 个**：答案不要求包含第 i 个 → 转移里天然有「不选它」这一支，`dp[i] = max(dp[i-1], ...)`
- **以 i 结尾**：必须包含 i → 子问题变成「上一个被选的 j 是谁」→ 需要 O(n) 内层枚举 j

这也是为什么 LIS 的朴素 DP 是 O(n²)，而打家劫舍是 O(n)。

### 五、初始化与"不可达"

| 值 | 含义 | 例子 |
|---|---|---|
| `0` | 合法的"最优值"（0 元需要 0 枚） | 零钱 `dp[0]=0` |
| `inf` | 不可达（暂时凑不出） | 零钱其余位置 |
| `-1` 或 `0` | 视题意 | 打家劫舍空数组返回 0 |

**别把"0"和"inf"混用**——零钱这题如果把 `dp` 全初始化为 0，答案会全错。

### 六、遍历顺序：只看"依赖谁"

| 依赖 | 正确顺序 | 例子 |
|---|---|---|
| `dp[i-1]`、`dp[i-2]` | i 从小到大 | 打家劫舍、零钱 |
| `dp[i+1][j-1]`（左下） | **按区间长度递增**（或 i 从大到小） | 回文子串 DP |
| 0-1 背包 | 容量**从大到小** | 每个物品只能用一次 |
| 完全背包 | 容量**从小到大** | 零钱（硬币可重复） |

### 七、空间优化三件套

1. **滚动变量**：只依赖前一两项 → 打家劫舍 `prev2, prev1`
2. **一维数组**：二维表中只用上一行 → 背包
3. **原地更新**：区间 DP 有时可以二维压一维（进阶）

### 八、怎么判断一道题能不能 DP

三个条件同时满足：

1. **最优子结构**：大问题的最优 = 小问题最优 + 一步决策
2. **无后效性**：过去的选择只通过"状态值"影响未来，不需要记住具体路径
3. **重叠子问题**：同一个子问题会被反复用到（否则不如直接递归/贪心）

### 九、你已经踩过 / 差点踩的坑

| 坑 | 题 | 教训 |
|---|---|---|
| 贪心当 DP | 零钱 `[1,3,4]/6` | 局部最优 ≠ 全局最优 |
| 状态定义含糊 | 层序/右视图 | 说清"每层取最后/首次到达" |
| 遍历顺序错 | 回文 DP | 必须按长度递增 |
| 答案位置错 | LIS | 答案是 `max(dp)` 不是 `dp[n-1]` |
| 只看局部 | BST 只比父子 | 全局约束要传上下界 |
| 复杂度写错 | 回文 DP 写 O(1) 空间 | 用了表格就是 O(n²) |

## AI

1. **DLR 不是不能判断**，而是先序序列没有单调性可利用 → 必须显式传 `(low, high)` 区间；
   中序则直接检查“严格递增”即可
2. **空间对比**：中序 + 数组 O(n)；中序 + `prev` O(h)；上下界递归 O(h)；Morris 中序 O(1)（但改树结构）
3. **只比较父子会错**：反例 `[10,5,15,null,null,6,20]`，`6` 是 `15` 的左孩子局部合法，
   但它在 `10` 的右子树里必须 > 10 → BST 是**全局约束**
4. 实现细节：必须严格递增（`<=` 即 false）；`prev` 可用 `-inf` 或 `None`
