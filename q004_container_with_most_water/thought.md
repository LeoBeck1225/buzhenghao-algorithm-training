# 004. 盛最多水的容器（#11）

- LeetCode: https://leetcode.cn/problems/container-with-most-water/
- 分类: 双指针
- 开始时间: 2026-11-22 00:15
- 用时: 约 20 分钟

## 我的第一想法（未使用 AI）

1. 暴力枚举肯定不行。可以使用双指针从最左、右出发逐步往中间收，面积由短的那一根决定
2. i=0,j=n-1，先算面积再移动直到i>=j
3.h[i]< h[j]，动短的那边h[i]。移动矮端不会漏解的原因是当前宽度已经最大，可以放心淘汰短端

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 边界情况

- `[1,8,6,2,5,4,8,3,7]` → `49`
- `[1,1]` → `1`
- `[4,3,2,1,4]` → `16`
- `[1,2,1]` → `2`
- `[1,1,1,1]` → `3`
- `[0,1,0]` → `0`
- `[2,3,4,5,18,17,6]` → `17`（相邻的高柱子）
- `[1,2,4,3]` → `4`
- `[2,3,10,5,7,8,9]` → `36`

## 卡住的地方 / 想向 AI 验证的点

- 循环条件用 i < j 而不是 i <= j
