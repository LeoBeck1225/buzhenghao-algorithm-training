## 经 AI 提示后的补充（这部分不是原话，单独记录）

### ① DLR 为何判断不了

准确说 DLR **能**判断，但不能“看序列”判断：
- **LDR（中序）**：序列天然严格递增 → 扫一遍即可，不需要额外约束
- **DLR（先序）**：先序序列既不递增也不递减，**没有可利用的单调性**
  → 必须把祖先的约束显式往下传，即 每个节点都落在 `(low, high)` 区间内

所以两种方案实质：
| 方案 | 靠什么保证正确 |
|---|---|
| 中序 | 序列严格递增 |
| 先序/任意序 + 上下界 | 每个节点落在祖先给的区间 |

### ② 哪种更省

| 实现 | 额外空间 | 说明 |
|---|---|---|
| 中序 + 存整个数组 | O(n) | 最后再判断数组递增 |
| 中序 + `prev` 变量 | **O(h)** | 边走边比，只留上一个值 |
| 上下界递归 | **O(h)** | 递归栈深度 |
| Morris 中序 | **O(1)** | 借叶子空指针，改树结构，面试可提 |

结论：中序 + `prev` 与上下界递归都是 O(h)，比存数组省。

### ③ 为什么只比较父子是错的

反例：
```
        10
       /  \
      5    15
          /  \
         6    20
```
- `6` 是 `15` 的左孩子，`6 < 15` → 局部合法
- 但 `6` 在 `10` 的右子树里，BST 要求 **> 10** → 全局违反

只比较父子会判 `true`，正确是 `false`。
本质：BST 是「左子树所有节点 < 根 < 右子树所有节点」的**全局约束**。

### ④ 实现细节

- 必须**严格递增**：`if node.val <= prev: return False`（`==` 也判 false）
- `prev` 初值用 `float("-inf")` 可行（节点值是 int，必然大于 -inf）；
  更严谨的写法是 `prev = None`，首次不比较
- 上下界版初值用 `±inf`，同理
