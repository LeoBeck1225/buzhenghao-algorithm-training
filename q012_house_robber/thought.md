# 012. 打家劫舍（#198）

- 开始时间: 2026-11-22 12:15

## 我的第一想法（未使用 AI，原文保留）

1. 在第i间房时，关心前面那一间偷没偷。从前i-1间和前i-2间找最优解(使用max())，若偷第i间则i-1间绝对不能偷，反之同理

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 边界情况

- [] → 0
- [5] → 5
- [1, 2] → 2
- [1, 3, 1] → 3
- [2, 1, 1, 2] → 4
- [1, 2, 3, 1] → 4

## 卡住的地方 / 想向 AI 验证的点

- dp[i] 到底该定义成“前 i 间房的最大值”，还是“第 i 间必偷时的最大值”？
- 为什么“不偷 i”是 dp[i-1]，而“偷 i”必须用 dp[i-2] 而不是 dp[i-1]？

## 经 AI 提示后的补充（这部分不是原话，单独记录）

### ① 两种 dp 定义都可行

| 定义 | 转移式 | 答案 |
|---|---|---|
| **A：前 i 间的最大（不要求偷 i）** | `dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])` | **`dp[n]`** |
| B：第 i 间必偷时的最大 | `dp[i] = nums[i] + max(dp[i-1], dp[i-2])` | `max(dp[1..n])` |

代码采用的是 **A**：答案直接就是 `dp[n]`，不用再求 max。

### ② 为什么“偷 i”必须用 dp[i-2]

1. 偷了 i ⇒ **i-1 绝对不能偷**
2. 既然 i-1 不偷，前 i-1 间的最优只能来自「前 i-2 间」

```
dp[i] = max( dp[i-1]            ← 不偷 i
             dp[i-2] + nums[i]  ← 偷 i，前 i-2 间最优 + 这间
           )
```

**关键**：`dp[i-2]` 表示「前 i-2 间的最优」，**不是“必偷 i-2”**，
所以 i-2 偷或不偷都已被包含，不会漏解。

若写成 `dp[i-1] + nums[i]`，`dp[i-1]` 的方案里可能已经偷了 i-1 → 违反相邻限制。

### ③ 空间优化：滚动变量

```
prev2 = 0   # dp[i-2]
prev1 = 0   # dp[i-1]
for x in nums:
    prev2, prev1 = prev1, max(prev1, prev2 + x)
return prev1
```

- 同时赋值，不会用错旧值
- 空数组：循环不执行，返回 0

### ④ 验证

- 10 条固定用例：滚动版 10/10、数组版 10/10
- 200 组随机数组（长度 ≤12）与「枚举所有不取相邻子集」的暴力对拍：**200/200**
