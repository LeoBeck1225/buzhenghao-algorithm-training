## 007. 删除链表的倒数第 N 个结点（#19）

- 工具：DSH（Coding Agent，本地 CLI）
- 模型：deepseek-flash
- 日期：2026-11-22

### 我的提示词 1

> 我的想法：一前一后双指针，前后相差 N，当后指针走到尾节点时前指针恰好在被删结点的前一个。
> 用 while 遍历，条件为后指针的 next。
>
> 卡住的地方：
> 1. 要不要用哑节点 dummy？
> 2. 前指针该放在 dummy 吗？
> 3. 要删除头节点该怎么做？

### AI 输出摘要 1

- **要用 dummy**：删除头节点时，慢指针需要停在"头的前一个"，而头没有前一个 → dummy 统一逻辑，免特判
- **前指针放 dummy**：`slow = fast = dummy`，`fast` 先走 n 步，此时两者恰好相差 n 个节点
- **删头怎么做**：由 dummy 化解。`fast` 走完 n 步即为 None，`while fast.next` 不执行，`slow` 停在 dummy，
  `slow.next = slow.next.next` 就把头节点删掉，返回 `dummy.next`
- 走查例子（`1→2→3→4→5`，n=2）：slow/fast 从 dummy 出发，fast 走到 3，同步走到结束，slow 停在 3，删 4
- 提醒两种写法不能混：`fast` 先走 n 步 + `while fast.next` 同步（推荐）；或用 `while fast.next` 作条件会差一步
- 边界建议：`[1],n=1`、`[1,2],n=2`（删头）、`[1,2],n=1`（删尾）、`[1,2,3],n=2`（删中间）
