# 011. 5. 最长回文子串

- LeetCode: https://leetcode.cn/problems/longest-palindromic-substring/
- 分类: 动态规划
- 开始时间: ____-__-__ __:__
- 用时: ____ 分钟

## 我的第一想法（未使用 AI）

1. 左右指针，同时设置一个变量odd用于判断不对称字符的数量，如果超过一个则左指针移到右指针的右边（此方法错误，我盲目套了另一道题）
2. 最优回文的中心不一定是起点，可以通过枚举中心，从中心向两边扩，2n-1个中心，每个中心扩到底取最长

## 复杂度

- 时间：O(n^2)
- 空间：O(1)

## 边界情况

- 
-  "" → ""
- "a" → "a"
- "aa" → "aa"
- "ab" → "a"
- "aba" → "aba"
- "abba" → "abba"
- "abb" → "bb"
- "cbbd" → "bb"
