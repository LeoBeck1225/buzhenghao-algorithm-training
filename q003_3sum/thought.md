# 003. 15. 三数之和

- LeetCode: https://leetcode.com/problems/3sum/
- 分类: 双指针
- 开始时间: ____-__-__ __:__
- 用时: ____ 分钟

## 我的第一想法（未使用 AI）

1. 固定i，然后按照j=i-1,k=i+1，以此类推的思路去寻找。两边同时往中间收缩，这样就是双指针
2. 判定i的重复：num[i]==num[i-1]时直接跳过；j一直+1知道num[j]和刚才记录的值不同；k与j对称，一直-1

## 复杂度

- 时间：O(n^2 )
- 空间：O(1)

## 边界情况

- n<3返回[];全0返回[[0,0,0]];全相同非0返回[];大量重复时检查去重
